\question \underline{Plotting a Function with Domain and Range:} We consider an algebraic function and graph it with it's domain and range.  Then, we add in some parameters to see how the domain and range changes.  Finally, we derive the inverse function and graph it with the appropriate domain.

\begin{parts}
	\part Open a new graph in Desmos and save it as ``Domain and Range."
	\part Graph the function $f(x) = \sqrt{x-1} + 5$ in Desmos.  Plot it in black with thickness value of 8.  In the space below, write down the domain and range of this function. 
	
		\textcolor{red}{Domain: $[1, \infty)$.  Range: $[5, \infty)$}
	
	\part Use Desmos to evaluate $f(3)$ correct to 4 decimal places.  What is $f(0)$?  
	
		\textcolor{red}{According to Desmos, $f(3)\approx 6.4142$ and $f(0)$ does not exist because $0$ is not in the domain.}
		
		
	\part Create a folder labeled ``Domain" and graph the domain on the $x$-axis.  To do this, type $y = 0 \{ x\geq ??\}$ on a new line, where the $??$ defines the boundary of the domain that you found above.  Plot this with a transparent value of $0.4$, thickness of $5$, and a color of blue. 
	\part Similarly, create a folder labeled ``Range" and graph the range on the $y$-axis.  To do this, type $x = 0 \{y \geq ??\}$ on a new line.  Plot this with a transparent value of $0.4$, thickness of $5$, and a color of red. 

	\part Modify the function $f(x)$ to be $f(x) = \sqrt{x-a} +b$. When prompted to add sliders for $a$ and $b$, select ``all."  Allow both $a$ and $b$ to range from $-10$ to $10$ with stepsize equal to $0.1$.  Push the play button on both parameters,  what happens to the graph? 
	
		\textcolor{red}{The graph essentially moves around with $a$ controlling the left and right movement, and $b$ controlling the up and down movement.  The two values of $a$ and $b$ control the horizontal and vertical shifts of the function.}
	
	\part In terms of $a$ and $b$, what is the new domain and range of $f(x)$?  Write the new domain and range below.  Modify your domain and range graphs so that they move with the function.  
	
		\textcolor{red}{Domain: $[a, \infty)$.  Range: $[b, \infty)$}

\question \underline{Piecewise Functions and Limits:} We consider a piecewise function that is split into three separate subdomains on the real number line.  We graph this function in Desmos and use it to evaluate limits.  


\begin{parts}
	\part Open a new graph in Desmos and save it as ``Piecewise Function."
	\part Define the following function in Desmos: 
		\[ f(x) = \displaystyle \begin{cases}  
				\frac{1}{2}x + 3 & x<0 \\ 
				\sin\left(\frac{\pi}{1-x}\right) & 0 \leq x<2 \\
				\frac{e^{-x/2}}{2} +3 & x\geq 2
			\end{cases} \]
	\part Notice that Desmos does not plot open and closed circles.  Plot appropriate open circles and closed circles where they are supposed to be in order for this function to be clearly defined.  Make all circles the same color as the graph with size 8.  
	\part What is the domain of this function?
	
		\textcolor{red}{The ``top'' and ``bottom'' functions are defined for all real numbers, but the ``middle'' function is undefined at $x = 1$.  Since the interval for the middle function contains 1, we see that this function's domain is $(-\infty, 1)\cup (1, \infty)$.  }

			

	\part Use the graph of $f(x)$ to evaluate the following limits and values: 
	
	\begin{minipage}{.5\textwidth}
		\begin{itemize}
			\item $\displaystyle \lim_{x\to -1^-} f(x) = \textcolor{red}{\frac{5}{2}}$
			\item $\displaystyle \lim_{x\to -1^+} f(x) = \textcolor{red}{\frac{5}{2}}$
			\item $\displaystyle \lim_{x\to -1} f(x) = \textcolor{red}{\frac{5}{2}}$
			\item $\displaystyle f(-1) = \textcolor{red}{\frac{5}{2}}$
			\item $\displaystyle \lim_{x\to 0^-} f(x) = \textcolor{red}{3}$
			\item $\displaystyle \lim_{x\to 0^+} f(x) = \textcolor{red}{0}$
			\item $\displaystyle \lim_{x\to 0} f(x) = \textcolor{red}{\text{DNE}}$
			\item $\displaystyle f(0) = \textcolor{red}{0}$
		\end{itemize}
	\end{minipage}
		\begin{minipage}{.5\textwidth}
		\begin{itemize}
			\item $\displaystyle \lim_{x\to 1^-} f(x) = \textcolor{red}{\text{DNE (oscillates forever)}}$
			\item $\displaystyle \lim_{x\to 1^+} f(x) = \textcolor{red}{\text{DNE (oscillates forever)}}$
			\item $\displaystyle \lim_{x\to 1} f(x) = \textcolor{red}{\text{DNE}}$
			\item $\displaystyle f(1) = \textcolor{red}{\text{undefined}}$
			\item $\displaystyle \lim_{x\to 2^-} f(x) = \textcolor{red}{0}$
			\item $\displaystyle \lim_{x\to 2^+} f(x) = \textcolor{red}{\frac{7}{2}}$
			\item $\displaystyle \lim_{x\to 2} f(x) = \textcolor{red}{\text{DNE}}$
			\item $\displaystyle f(2) = \textcolor{red}{\frac{7}{2}}$
		\end{itemize}
	\end{minipage}
	
	\part Does this function have any horizontal asymptotes?  Write down explicit limits below that justify your answer. 
	
			\textcolor{red}{Yes, from the graph, we can see that on the right hand side, the function is becoming more horizontal.  Therefore, as $x\to \infty$, we have $f(x) \to 3$, or in limit form 
			\[ \lim_{x\to\infty} f(x) = 3 \qquad \Rightarrow \qquad \text{Horizontal Asymptote at $y = 3$.} \]}

	
	\part When you submit this assignment on Desmos, share the url to this graph.  

	\textcolor{red}{\texttt{https://www.desmos.com/calculator/bixhwuqs9d}}

	
\end{parts}
