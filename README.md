# Kutztown University Calculus Desmos Library

**Project Directors:** Dr. Brooks Emerick and Dr. Yun Lu  
**Institution:** Kutztown University, Department of Mathematics  
**Funding:** Supported by the PASSHE Faculty Professional Development Council (FPDC) Grant

## Project Overview
This repository contains a comprehensive library of interactive Desmos programs designed to enhance student learning outcomes and engagement in the Calculus sequence (Calculus I, II, and III). These visual activities were developed to provide an interactive platform for exploring graphical representations of functions, applications, definitions, and theorems, thereby deepening students' conceptual understanding of calculus.
